\# docy



A lightweight Android file manager with a built-in code editor, Markdown renderer, and archive tools.



Features:

\- File browsing with list/grid view, sorting, breadcrumbs, and multi-select

\- File operations: copy, move, rename, delete, compress, extract

\- Code editor: syntax highlighting, auto-completion, static linting, find/replace

\- Markdown reader with GFM tables, strikethrough, autolinks, and task lists

\- Archive support: list/extract ZIP, 7z, RAR, TAR, GZ; compress to ZIP and 7z

\- LÖVE 2D project packaging and launching

\- Dark / light theme with Material 3



Modules:

\- `:app` – UI and platform integrations

\- `:core` – domain models and shared types

\- `:fs` – file system operations and archive manager

\- `:editor` – code editor, linters, syntax highlighters, plugin system

\- `:designsystem` – Compose components and theme



Build:



`./gradlew assembleDebug`

\# docy



一个轻量的 Android 文件管理器，集成了代码编辑器、Markdown 阅读和压缩包管理。



功能：

\- 文件浏览：列表/网格视图、排序、面包屑、多选

\- 文件操作：复制、移动、重命名、删除、压缩、解压

\- 代码编辑器：语法高亮、自动补全、静态检查、查找替换

\- Markdown 阅读：支持表格、删除线、自动链接、任务列表

\- 压缩包支持：浏览/解压 ZIP、7z、RAR、TAR、GZ；压缩为 ZIP、7z

\- LÖVE 2D 项目打包与运行

\- 暗色/亮色主题，Material 3



模块结构：

\- `:app` – UI 和平台集成

\- `:core` – 领域模型和共享类型

\- `:fs` – 文件系统操作和压缩包管理

\- `:editor` – 代码编辑器、Linter、语法高亮、插件系统

\- `:designsystem` – Compose 组件和主题



构建：



`./gradlew assembleDebug`
